## 🛠️ Tech Stack

- **Frontend:** [React.js](https://reactjs.org/) + [Three.js](https://threejs.org/) (3D Graphics)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Glassmorphism UI)
- **Backend:** [Flask](https://flask.palletsprojects.com/) (Python)
- **Database:** [Google Sheets API](https://developers.google.com/sheets/api)
- **Deployment:** [Render](https://render.com/)

## ✨ Key Features

- **Interactive 3D Background:** Floating geometric shapes that react to mouse movement and "explode" upon successful subscription.
- **Automated Data Entry:** Emails are instantly appended to a Google Sheet with a precise timestamp.
- **Secure Architecture:** Uses Google Service Account credentials managed via environment variables to prevent API key leaks.
- **Responsive Design:** Fully optimized for mobile and desktop viewports.
